Senior-Friendly UI Generator

A reusable AI-assisted UX skill for generating senior-friendly interface patterns from research insights and competitor analysis.

01 — Overview

Understanding where older adults experience friction in digital services.

01
Cognitive Friction
  • Too much information at once
  • Ambiguous labels and icons
  • Unclear error messages
  • No confirmation before actions
02
Visual Friction
  • Low contrast text
  • Small tap targets
  • Dense layouts with no whitespace
  • Reliance on color alone for state
03
Interaction & Navigation
  • Multi-step flows with no progress
  • Hidden navigation patterns
  • Time-limited sessions
  • No easy way to undo actions

02 — Design Focus

Designing for older adults managing important life and service tasks.

👁️
Aging-Related UX
  • Larger tap targets (minimum 44px)
  • High contrast ratios (7:1 for body text)
  • Reduced cognitive load per screen
  • Explicit, action-oriented labels
⚡
P-UX (Priority)
  • Primary actions always visible
  • Secondary actions clearly deprioritized
  • Consistent placement across screens

03 — Key Insight

Older adults do not only need larger text — they need clearer paths, trust, and recovery.

PATH CLARITY

Users need to understand what will happen before they click.

Vague button labels and unlabeled icons cause hesitation and wrong-path selections that erode trust.

TRUST SIGNALS

Older adults are more sensitive to signs of legitimacy and security.

Missing confirmation dialogs, sudden page changes, or ambiguous form feedback increase abandonment.

RECOVERY

Easy undo and clear error recovery are more valuable than preventing errors alone.

When errors occur, plain-language explanations and a clear path forward matter more than technical details.

04 — Skill Application

Applying the skill to a real public-service task.

Using competitor analysis of government and financial service UIs, the skill generates interface patterns that meet both WCAG 2.1 AA and senior-specific guidelines simultaneously.

Component Standard Pattern Senior-Optimized
Button 36px height, 3:1 contrast 48px height, 7:1 contrast, text label always
Form input Placeholder text only Persistent label above, inline helper text
Error state Red border + icon Red border + plain-language fix instruction
Navigation Hamburger menu on mobile Persistent bottom nav, max 4 items
Progress Step dots Numbered steps with labels ("Step 2 of 4")
Confirmation Toast notification Modal confirmation with action summary

05 — Principles

8 UI principles for senior-friendly digital services.

1
Readability
Minimum 16px body text, 7:1 contrast, generous line spacing.
2
Logical & Minimal
One primary action per screen. Remove decorative elements.
3
Simplicity
Plain language, no jargon, explicit labels on all controls.
4
Contrast & Color
Never use color as the only indicator of state or meaning.
5
Contextual Feedback
Immediate, plain-language feedback on every action.
6
Simplify Language
Active voice, short sentences, avoid abbreviations.
7
Remove Barriers
48px tap targets, keyboard navigable, no time limits.
8
Calibrate & Encourage
Progress indicators, undo options, encouraging microcopy.

06 — Workflow

A repeatable workflow for AI-assisted inclusive design.

STEP 01

Input

Provide a service description or screen goal. Optionally include competitor screenshots.

STEP 02

Analysis

AI maps the service against the 8 principles and identifies friction points.

STEP 03

Generate

Skill outputs annotated wireframe patterns with component specs and copy guidance.

STEP 04

Refine

Designer reviews, adjusts for context, and exports to Figma or Markdown.

Senior-Friendly UX is not about making products simpler for one group. It's about making essential digital services clearer, safer, and more trustworthy for everyone.

The principles were turned into a reusable Markdown skill file — a template that turns research into consistent, AI-ready design rules applicable across any public service interface.
